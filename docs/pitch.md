## เตรียมตอบ

| กรรมการถาม | ตอบ |
|---|---|
| ต่างจาก ChatGPT shopping หรือ agent หาดีลยังไง | ตัวหาดีลตอบว่าตัวไหนถูก ระบบเราตอบว่าตัวไหนเหมาะ ผ่านเรื่องที่ต้องมีไหม พร้อม quote ทุกข้อ ข้อมูลไม่พอก็บอกว่าไม่พอ ส่วนอันดับคิดด้วยโค้ดจึงได้ผลเดิมทุกครั้ง |
| ทำไมต้องมีหลาย agent | แต่ละตัวมีเป้าที่ขัดกัน คือเหมาะที่สุด ถูกที่สุด และตัวที่คอยค้าน อันดับ 1 ต้องรอดจาก Skeptic ก่อนขึ้นการ์ด ถ้ามีตัวเดียวจะไม่มีใครแย้ง |
| AI แต่ง quote ได้ไหม | tool `propose` เช็กว่า quote เป็นข้อความที่อยู่ในรีวิวจริง ถ้าไม่ใช่ก็ตีกลับ |
| ข้อมูลมาจากไหน | ข้อมูลสังเคราะห์ที่ทีมเตรียมเอง ไม่ดึงจาก Shopee เพราะ ToS ข้อ 3.1 ห้าม ของจริงต้องใช้ข้อมูลจาก Sea |
| LLM ล่มกลางเดโม | ระบบเล่นซ้ำจาก cache ได้ และมีโหมดกฎที่ให้ผลรูปแบบเดียวกัน |
| ใช้ Codex ยังไง | ทุกชิ้นสร้างจาก prompt ใน `docs/codex-prompts.md` ดูได้จาก commit ทีละชิ้น |
