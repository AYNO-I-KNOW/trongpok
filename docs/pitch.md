## เตรียมตอบ

| กรรมการถาม | ตอบ |
|---|---|
| ต่างจาก ChatGPT shopping หรือ agent หาดีลยังไง | ตัวหาดีลตอบว่าตัวไหนถูก ระบบเราตอบว่าตัวไหนเหมาะ ผ่านเรื่องที่ต้องมีไหม พร้อม quote ทุกข้อ แยกรีวิวตอนแกะกล่องออกจากรีวิวที่ใช้นาน ข้อมูลไม่พอก็บอกว่าไม่พอ และโค้ดเป็นคนจัดอันดับ |
| จับรีวิวปลอมได้ไหม | ไม่ได้อ้างว่าจับได้ ระบบให้น้ำหนักรีวิวชมลอยๆ แค่ 0.3 แต่ให้รีวิวที่ค้านน้ำหนักเต็ม และโชว์สัดส่วนรีวิวคุณภาพต่ำให้คนเห็นเอง |
| ทำไมต้องมีหลาย agent | แต่ละตัวมีเป้าที่ขัดกัน: เหมาะที่สุด ถูกที่สุด และตัวคอยค้าน อันดับ 1 ต้องรอดจาก Skeptic ก่อน |
| AI แต่ง quote ได้ไหม | tool `propose` ตีกลับ quote ที่ไม่ได้อยู่ในรีวิวจริง |
| ข้อมูลมาจากไหน | ข้อมูลสังเคราะห์ที่ทีมเตรียมเอง เคสแผ่นแดมป์มาจากประสบการณ์จริงของทีม ไม่ดึงจาก Shopee เพราะ ToS ข้อ 3.1 ห้าม |
| LLM ล่มกลางเดโม | เล่นซ้ำจาก cache ได้ และมีโหมดกฎที่ให้ผลรูปแบบเดียวกัน |
| ใช้ Codex ยังไง | ทุกชิ้นสร้างจาก prompt ใน `docs/codex-prompts.md` ดูได้จาก commit และ PR |
