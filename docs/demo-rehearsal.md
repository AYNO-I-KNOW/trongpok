# ซ้อมเดโมตรงปก 6 นาที

ตาม [รูปแบบการตัดสิน](hackathon.md) ทั้งสองรอบมีเวลา Demo/Pitch 6 นาที รอบแรกมี Q&A 2 นาที รอบชิงมี Q&A 4 นาที ให้ใช้ Arena เครื่องปั่นเป็นเดโมหลัก เพราะเปิดดูข้อทักท้วงกับรีวิวต้นทางได้โดยไม่ต้องใช้คีย์

## เตรียมก่อนซ้อม

1. จากราก repo ให้รัน `npm ci` แล้วรัน `npm run eval -- --demo` คำสั่งสร้าง [รายงานเดโม](../data/cache/eval-report.json) จากข้อมูลสังเคราะห์ โดยไม่เรียก OpenAI และไม่ต้องเตรียมผล Arena ไว้ก่อน
2. เปิดเซิร์ฟเวอร์ด้วย `OPENAI_API_KEY= OPENAI_MODEL= npm run dev` แล้วเปิด [หน้าแรก](http://localhost:3000/) กับ [ผลประเมิน](http://localhost:3000/eval) คนละแท็บ
3. ซ้อมเส้นทาง Arena ด้านล่างในหน้าจอมือถือให้ถึงรีวิว `r5` และเปิดลิงก์ต้นทางให้ได้ก่อนเริ่มจับเวลา กลับมาที่หน้าแรกก่อนเริ่มเดโม

### เปิดโจทย์เครื่องปั่นและตรวจหลักฐาน

1. ที่ `/` กด **ลอง Arena** เพื่อไปที่ `/arena` กด **ลองโจทย์ตัวอย่าง** หรือพิมพ์ `เครื่องปั่นไว้ปั่นน้ำแข็งเปิดร้าน งบ 3,000 บาท` แล้วส่งโจทย์
2. เลือก **บดน้ำแข็ง** แล้วกด **ถัดไป** เลือก **8 ก้อน** แล้วกด **ถัดไป** เลือก **โถปั่นหลัก** แล้วกด **ดูสรุปเงื่อนไข**
3. ที่หน้า **เงื่อนไขที่จะใช้เปรียบเทียบ** ตรวจการบดน้ำแข็ง จำนวนก้อน ภาชนะ และงบ 3,000 บาท แล้วกด **เริ่มค้นหาต่อ**
4. ที่ตารางผล ชี้ป้าย **ข้อมูลเดโมสังเคราะห์ · ราคาและรีวิวไม่ใช่ข้อมูลจริง** เปิด **เหตุผลและหลักฐาน** แล้วกด **ดูหลักฐาน** ในคอลัมน์ **เครื่องปั่นครอบลดเสียง โถ 1.5 ลิตร 1000W**
5. ใต้ **ข้อทักท้วงจาก Skeptic** ชี้ **รีวิวต้นทาง r5** และอ่านข้อความนี้ตามต้นฉบับ:

   > ใช้มา 3 เดือน น้ำแข็งก้อนใหญ่ต้องแบ่งใส่สองรอบ แต่ไม่มีกลิ่นไหม้

6. กด **เปิดข้อมูลต้นทางในแคตตาล็อกเดโม** ซึ่งเปิด [`/api/demo-products/blender-quiet-daily`](http://localhost:3000/api/demo-products/blender-quiet-daily) แล้วหา `r5` ใน JSON เพื่อเทียบข้อความ ลิงก์นี้เป็นแคตตาล็อกในแอป ไม่ใช่หน้าร้านหรือรีวิวจากเว็บ
7. กลับไปที่ผล Arena ปิดกล่องหลักฐาน แล้วเปิด **วิธีใช้และข้อจำกัด** ชี้แถว **ปั่นน้ำแข็ง 8 ก้อน ในโถหลัก** ที่ขึ้นว่า **ข้อมูลไม่พอ** รีวิว `r5` บอกว่าต้องแบ่งน้ำแข็งก้อนใหญ่เป็นสองรอบ แต่ไม่บอกว่าบดได้กี่ก้อนต่อรอบ ความจุโถ 1.5 ลิตรไม่ได้ยืนยันว่าบด 8 ก้อนในโถหลักได้

### อ่านผลประเมินโดยไม่สรุปเกินข้อมูล

ที่ `/eval` ให้ชี้จำนวนโจทย์ที่วัดได้ อัตราที่อันดับหนึ่งตรงกับอันดับอ้างอิง และจำนวนสินค้าเฉลี่ยที่ตรงกันในสามอันดับแรก ถ้าเปิด JSON ให้ใช้ `curl -H 'Accept: application/json' http://localhost:3000/api/eval` ซึ่งอ่านรายงานเดียวกัน

- อัตราอันดับหนึ่งไม่ผ่านข้อจำเป็นใช้เฉพาะโจทย์ที่มี `must_notes` ช่องว่างคือไม่มีบันทึก ไม่ใช่หลักฐานว่าอันดับหนึ่งผ่าน
- ค่าที่วัดไม่ได้ไม่ใช่ศูนย์ เช่น การให้โมเดลเลือกโดยตรงไม่ทำงานในเดโมโหมดกฎ ผลทั้งหมดมาจากโจทย์และแคตตาล็อกสังเคราะห์ ไม่ได้วัดยอดคืนสินค้าหรือพฤติกรรมผู้ซื้อจริง

## ซ้อมการค้นเว็บแยกจาก Arena

1. ถ้าจะลองหน้าแรกแบบค้นเว็บ ให้ตั้ง `OPENAI_API_KEY` และ `OPENAI_MODEL` ตาม [README](../README.md#ลองค้นสินค้าจากเว็บ) แล้วเริ่ม `npm run dev` ใหม่โดยไม่ล้างตัวแปร เปิด `/` และพิมพ์ `หาเมาส์ไร้สายคลิกเงียบ งบไม่เกิน 1,000 บาท`
2. ถ้าเห็น **ค้นจากเว็บ** และมีรุ่นที่ยืนยันได้ ให้เปิด **เหตุผลและหลักฐาน** แล้วกด **ดูหลักฐาน** ของรุ่นนั้น ชี้หน้าสินค้าตรงรุ่น แหล่งที่ยืนยันว่าคลิกเงียบ และที่มาของราคาไทย แสดงเฉพาะผลที่รันนั้นพบจริง ราคาอาจเปลี่ยนได้
3. ถ้าเห็น **ยังไม่มีรุ่นที่ยืนยันได้** หรือ **ยังตรวจเรื่องนี้ไม่ได้** ให้กด **ลองค้นอีกครั้ง** หรือกลับไปเดโมหลัก อย่าใช้ชื่อรุ่นหรือราคาจากรอบก่อนแทนผลที่ยังยืนยันไม่ได้
4. ถ้าต้องการให้เห็นผลสำรองของหน้าแรก ให้ใช้เซิร์ฟเวอร์แบบไม่ตั้งคีย์และพิมพ์ `เครื่องปั่น งบ 999 บาท` ชี้ป้าย **โหมดกฎ · ข้อมูลเดโม** และบอกว่ารุ่นกับราคาเป็นข้อมูลสังเคราะห์ โจทย์เมาส์ไม่อยู่ในชุดเดโม จึงใช้สาธิตสถานะให้ลองค้นใหม่ได้ แต่ใช้สาธิตแคตตาล็อกไม่ได้

## เตรียมตอบ Q&A

- **เครื่องครอบลดเสียงบด 8 ก้อนได้ไหม?** ยังยืนยันไม่ได้ รีวิว `r5` ระบุว่าต้องแบ่งรอบ แต่ไม่ได้ระบุจำนวนก้อนหรือเงื่อนไขที่คู่มือรองรับ
- **AI จัดอันดับเองไหม?** โค้ดคำนวณคะแนนและจัดอันดับ โมเดลช่วยอ่านเงื่อนไขและหลักฐานเมื่อเปิดใช้ ระบบไม่แสดง quote ถ้าไม่มีข้อความนั้นในรีวิวต้นทาง
- **ข้อมูลมาจากไหน?** Arena และผลประเมินใช้ชุดสังเคราะห์ที่ทีมเตรียมไว้ การค้นเว็บบนหน้าแรกเป็นอีกเส้นทางและใช้เว็บผู้ผลิตหรือร้านค้าที่อนุญาตเท่านั้น ไม่ดึงข้อมูลจาก Shopee
- **Codex มีส่วนตรงไหน?** เปิด [ชุดโจทย์ Codex](codex-prompts.md) ตอน S04 เพื่อชี้เงื่อนไขปฏิเสธ quote ที่ไม่ตรงต้นทาง และตอน S06 เพื่อชี้โจทย์วัดอันดับเทียบ baseline
