# แผนค้นสินค้าจริงจากเว็บและแสดง Top 3 ในตรงปก

ผู้ซื้อพิมพ์โจทย์สินค้าอะไรก็ได้ในหน้าแรก เช่น **หาเมาส์ไร้สายคลิกเงียบ งบ 1,000 บาท** ตรงปกค้นเว็บจริง คัดตัวเลือก และแสดง Top 3 ในหน้าเดียวกัน แต่ละใบมีชื่อรุ่น ราคาเมื่อยืนยันได้ เหตุผลที่ตรงโจทย์ ข้อที่ยังยืนยันไม่ได้ และลิงก์ต้นทาง ผู้ซื้อใช้เว็บได้โดยไม่ต้องมีบัญชี Codex

## ลำดับก่อนส่ง

1. ทำ P0 ให้พิมพ์โจทย์ใหม่และได้ผลค้นจริงครบทั้งเส้นทาง ใช้เวลาที่เหลือแก้ผลที่ผิดหมวด หลุดงบ หรืออ้างอิงผิดรุ่นก่อนเพิ่มส่วนอื่น
2. ทำ P1 เมื่อ P0 ผ่านการทดสอบบนเว็บที่ deploy แล้ว ใช้ชุดข้อมูลเดโมสำหรับโชว์ Arena และเป็นทางสำรองเมื่อค้นเว็บไม่ได้
3. กันช่วง 16:15 ถึง 17:00 น. ตามแผนทีมไว้ตรวจเว็บและซ้อมเดโม เส้นตายผู้จัดคือ 17:00 น. เวลาไทย [แผนทีม](codex-prompts.md) · [กำหนดการผู้จัด](hackathon.md)

## P0 ค้นจริงจากช่องค้นเดิมและจัด Top 3

- [x] ส่งข้อความจากช่องค้นเดิมไปยัง `POST /api/product-search` ให้เส้นทางปกติใช้โจทย์ของผู้ซื้อโดยตรง ข้ามการแทนโจทย์ที่ระบบไม่รู้จักด้วยหมวดเครื่องปั่นและหยุดใช้ผลพรีวิวสำหรับเส้นทางนี้ ใช้สถานะโหลดจากคำขอจริง [ช่องค้นหาและหน้าผล](../src/ui/trong-pok/components/SearchHome.tsx)
- [x] ให้เซิร์ฟเวอร์ใช้ OpenAI Responses API และ `web_search` โดยเลือกโมเดลจาก `OPENAI_MODEL` ที่รองรับเครื่องมือ บังคับให้ค้นในเส้นทางนี้ จำกัดแหล่งค้นไว้ที่เว็บไซต์ผู้ผลิตและร้านค้าที่ทีมอนุญาต ครอบคลุมสินค้าหลายหมวดและกันโดเมน Shopee ก่อนเรียกค้น เก็บ URL ที่เครื่องมือรายงานเป็นแหล่งข้อมูลสำหรับตรวจผล [เอกสาร Web search](https://developers.openai.com/api/docs/guides/tools-web-search) · [กติกาแหล่งข้อมูล](../AGENTS.md#L27)
- [x] รับโจทย์เป็นข้อความอิสระ แยกงบ ข้อจำเป็น และข้อที่อยากได้จากข้อความโดยไม่บังคับให้เข้า category pack เดิม ถ้าพอค้นได้ให้ค้นทันที ถ้าขาดรายละเอียดจนเลือกสินค้าไม่ได้ให้ถามต่อหนึ่งข้อบนหน้าเดิม
- [x] ดึงตัวเลือกมากกว่า 3 รุ่น ตรวจข้อมูลจากเครื่องมือด้วย Zod และใช้รูปแบบผลที่รองรับสินค้าหลายหมวด เก็บชื่อรุ่น URL ราคาและเวลาที่พบราคา สถานะสินค้า และหลักฐานรายข้อ ตรวจ URL กับแหล่งที่เครื่องมือค้นคืนมาและรวมรุ่นเดียวกันที่เจอหลายร้าน ใช้ **ข้อมูลไม่พอ** เมื่อแหล่งที่มาขาดข้อมูล
- [x] ให้โค้ดจัดอันดับตามข้อจำเป็นที่มีหลักฐานและงบ แล้วใช้ข้อที่อยากได้กับราคาเรียงลำดับต่อ ส่งคืน 3 รุ่นที่ต่างกันเมื่อพบเพียงพอ ตัดรุ่นที่เกินงบหรือผิดข้อจำเป็นที่ยืนยันได้ รวมถึงข้อเสนอที่ร้านระบุว่าหมดสต็อก ถ้ายังไม่ครบ ให้ค้นเพิ่มด้วยชื่อเรียกหรือคำค้นใกล้เคียงโดยคงข้อจำเป็นเดิม ถ้ายังได้ไม่ครบ ให้แสดงจำนวนที่ยืนยันได้และระบุข้อที่ติดอยู่ [กติกาการจัดอันดับ](../AGENTS.md#L30)
- [x] แสดง **ค้นจากเว็บ** บนหน้าผล และใส่ลิงก์ต้นทางติดกับราคาและสเปกที่อ้าง ใช้หลักฐานจากหน้าสินค้าหรือคู่มือเป็นข้อมูลสเปก แสดงสถานะรีวิว **ข้อมูลไม่พอ** เมื่อขาดหลักฐานที่เข้าเกณฑ์ [กติการีวิว](../AGENTS.md#L31) · [การแสดงแหล่งอ้างอิง](https://developers.openai.com/api/docs/guides/tools-web-search#output-and-citations)
- [x] เมื่อ API ใช้ไม่ได้หรือขาด `OPENAI_API_KEY` หรือ `OPENAI_MODEL` ให้เว็บแจ้งสถานะและเปิด **โหมดกฎ · ข้อมูลเดโม** สำหรับโจทย์ที่ catalog รองรับ โจทย์นอกชุดเดโมให้เสนอให้ลองค้นใหม่โดยเก็บคำค้นไว้ [กติกาโหมดกฎ](../AGENTS.md#L34)
- [x] ทดสอบมือถือจากหน้าแรกด้วย 3 โจทย์ที่ผู้ทดสอบเลือกเอง ครอบคลุมอย่างน้อย 2 หมวดนอกชุดเดโม ทดสอบโจทย์ทั่วไปที่มีตัวเลือกพอและโจทย์ที่จำกัดจนผลไม่ครบ ตรวจว่าคำขอที่สำเร็จมี `web_search_call` จริง ทั้ง 3 รุ่นเปิดไปยังแหล่งตรงรุ่นได้ และอันดับเปลี่ยนตามโจทย์เมื่อเปลี่ยนงบหรือข้อจำเป็น

**ข้อกำหนดแหล่งข้อมูล** หน้าแรกใช้เว็บผู้ผลิตและร้านค้าในรายการที่อนุญาต ส่วน Arena และโหมดกฎใช้ชุดเดโม โค้ดจัดอันดับทั้งสองเส้นทาง [กติกาโครงการ](../AGENTS.md#hard-rules)

- [ ] ใช้ `/api/arena` โชว์เคสสินค้าและรีวิวสังเคราะห์หนึ่งเคสพร้อมป้ายที่มา เปิดข้อความที่ Skeptic ยกมาค้านได้ และระบุเมื่อเล่นซ้ำจาก cache [Arena API](../src/app/api/arena/route.ts#L5) · [กติกาชุดข้อมูล](../data/README.md#L1)

## ซ้อมเดโมให้จบใน 6 นาที

1. ใช้ 45 วินาทีเล่าปัญหาคนซื้อที่มีเงื่อนไขมากกว่าชื่อหมวดสินค้า
2. ใช้ 75 วินาทีให้กรรมการเลือกโจทย์สินค้าแล้วพิมพ์บนหน้าเว็บตรงปก แสดง Top 3 จากการค้นเว็บ
3. ใช้ 90 วินาทีเปิดลิงก์ที่มาของหนึ่งรุ่น แล้วให้กรรมการเปลี่ยนงบหรือข้อจำเป็นเพื่อดูผลค้นและอันดับใหม่
4. ใช้ 90 วินาทีโชว์หลักฐานการตรวจผลและงานที่ Codex ช่วยสร้าง ถ้า Arena พร้อมแล้วให้ใช้เคสสังเคราะห์ที่ติดป้ายข้อมูลเดโม
5. ใช้ 60 วินาทีสรุปว่าตัวเลือกไหนเหมาะกับโจทย์ เพราะข้อไหน และผลยังขาดข้อมูลอะไร
