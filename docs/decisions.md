# เปลี่ยนแกนเป็น "เหมาะกับเรา + ตรงปก" และ agent arena (2026-11-20 ดึก)

ที่มา: [meetings/2026-11-20-purchase-fit-agent-idea.md](meetings/2026-11-20-purchase-fit-agent-idea.md) ทีมตกลงให้ไอเดียผ่าน และผู้ใช้เลือกทั้ง 3 จุดตามข้อเสนอ

แทนที่ใน [2026-11-20-scope-decisions.md](2026-11-20-scope-decisions.md): Q6/Q14 (เคสชุดนอนกับพาวเวอร์แบงก์), Q11 (ตะกร้า), Q12 (LINE OA เป็นงานหลัก), Q17 (ชุดติดป้ายราย claim) ข้ออื่นยังใช้ต่อ

## Pain point

คนซื้อตามดาวกับรีวิว แต่ดาว 4.8 บอกว่า**คนอื่น**พอใจกับการใช้งาน**ของเขา** ไม่ได้บอกว่าเหมาะกับเรา ผลคือได้ของที่ไม่ได้ใช้ หรือจ่ายแพงให้แบรนด์ดังเพื่อฟีเจอร์ที่ไม่เคยเปิดใช้ ส่วนคนที่คืนของให้ดาวไม่ได้ (Help 80883) ดาวจึงซ่อนเคสที่ "ไม่เหมาะ" มากที่สุดไว้ด้วย

- เครื่องปั่น: จะเปิดร้านต้องปั่นน้ำแข็งได้ เครื่อง 4.8★ คนรีวิวใช้ปั่นสมูทตี้ แต่ 6 รีวิวบอกว่าปั่นน้ำแข็งแล้วมอเตอร์ไหม้
- Smartwatch: ต้องการแค่แจ้งเตือน LINE นับก้าว และแบตอยู่ได้ 7 วัน แต่จ่าย 12,000 บาทให้ GPS, ECG และ eSIM ที่ไม่เคยใช้

## ข้อตกลง

| เรื่อง | ข้อตกลง |
|---|---|
| แกน | ความต้องการ → ข้อที่ต้องมี (must) / ข้อที่อยากได้ (nice) / งบ → ตรวจแต่ละข้อจากสเปกและรีวิวพร้อม quote → หลักฐานบางขึ้นว่าข้อมูลไม่พอ ตรงปกกลายเป็นคำถามว่า "สเปกบอกว่าได้ แต่ผู้ใช้จริงบอกว่าได้ไหม" |
| Arena | 4 agent คนละเป้าหมาย: **Verifier** ตรวจตัวที่ผู้ใช้ส่งมา · **Fit** หาตัวที่เหมาะที่สุด · **Value** หาตัวที่ถูกที่สุดที่ผ่าน must ทุกข้อ · **Skeptic** หารีวิวมาแย้งตัวที่อยู่อันดับต้น โค้ดเป็นคนจัดอันดับ judge เป็นคนเขียนเหตุผล ผู้ใช้ตัดสินใจเอง |
| แหล่งข้อมูล | หาสินค้าจากชุดเดโมที่ทีมเขียนเอง ส่วน OpenAI web search ใช้แค่ยืนยันสเปกพร้อมแหล่งที่มา ตัดทิ้งได้ และไม่ scrape Shopee |
| ทางเข้า | ลิงก์สินค้า (แล้วตรวจด้วย Verifier) หรือพิมพ์ความต้องการ จากนั้นถามต่อเป็นปุ่มตัวเลือก (ใช้ทำอะไร, งบ, ต้องมีอะไร) |
| ผลลัพธ์ | arena ที่เห็นแต่ละ agent ทำงานไปพร้อมกัน → การ์ดใหญ่ 1 ใบกับการ์ดเล็ก 3 ใบ แต่ละใบมี "เหมาะ X%", ผลราย requirement พร้อม quote, ข้อคัดค้านของ Skeptic และ "ประหยัด ฿X เทียบกับตัวที่ดาวสูงสุด" |
| เคสเดโม | เครื่องปั่น (เข้าด้วยลิงก์) และ smartwatch (เข้าด้วยการพิมพ์ความต้องการ) |
| พิสูจน์ | persona 8 คน หมวดละ 4 คน ทีม 2 คนจัดอันดับ top 3 แยกกัน แล้ววัด top-1 hit กับ top-3 overlap เทียบกับเรียงตามดาว เรียงตามยอดรีวิว และให้ LLM เลือกเอง |
| ตัด | ตะกร้ากับ LINE OA เป็นงานเสริม ทำหลังของหลักเสร็จเท่านั้น (meeting: "อยากให้มีฟีเจอร์หลักที่ดีจริงอันเดียว") |

## เหตุผลที่เลือก 4 บทบาท

prompt ที่เหมือนกันจะทำให้ agent แค่ช่วยกันค้น ไม่ได้แข่งกัน (ฟู) ส่วนบทบาท "สุ่ม" ไม่มีเป้าที่วัดได้ จึงใช้ Skeptic แทน Skeptic ทำให้ arena มีเหตุผลที่จะมีอยู่ เพราะอันดับ 1 ต้องรอดจากหลักฐานแย้งก่อนขึ้นการ์ดใหญ่ และคำถามของอบว่า "ทำไมต้องเสนอตัวอื่นทั้งที่ลูกค้าไม่ได้ขอ" ตอบได้ด้วยข้อที่ Verifier ไม่ผ่าน กับเงินที่ Value ประหยัดให้ได้
