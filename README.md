# ตรงปก (trongpok)

ดาวสูงบอกว่าคนอื่นชอบสินค้า แต่ไม่ได้บอกว่าเครื่องปั่นจะบดน้ำแข็ง 8 ก้อนในโถหลักได้ไหม ตรงปกให้ผู้ซื้อระบุวิธีใช้ ข้อที่ต้องมี และงบ แล้วแสดงหลักฐานที่รองรับหรือค้านแต่ละข้อ ถ้าหลักฐานไม่พอ ระบบบอกว่ายังยืนยันไม่ได้ ผู้ซื้อเป็นคนตัดสินใจเอง

## เปิดเดโมในเครื่อง

ใช้ Node.js ตาม `engines.node` ใน [`package.json`](package.json): `^22.13.0 || ^24.0.0 || >=26.0.0`.

```sh
npm ci
npm run eval -- --demo
OPENAI_API_KEY= OPENAI_MODEL= npm run dev
```

- [`/`](http://localhost:3000/) เป็นหน้าแรกสำหรับพิมพ์โจทย์ซื้อของหรือกด **ลอง Arena** เมื่อไม่ตั้งค่าคีย์และโมเดล หน้าแรกค้นได้เฉพาะแคตตาล็อกสังเคราะห์ในหมวดที่รองรับ ไม่ใช่ราคาขายจริง
- [`/arena`](http://localhost:3000/arena) เป็นเดโมเครื่องปั่นแบบถามทีละข้อและแสดงตารางเปรียบเทียบ เปิดรีวิวต้นทางของข้อทักท้วงได้ สินค้า ราคา และรีวิวใน Arena เป็นข้อมูลสังเคราะห์ แม้เปิดใช้โมเดล
- [`/eval`](http://localhost:3000/eval) แสดงตารางภาษาไทยจาก [รายงานที่สร้างไว้ใน repo](data/cache/eval-report.json) อ่านรายงานเดียวกันเป็น JSON ได้ด้วย `GET /api/eval` พร้อม `Accept: application/json`:

```sh
curl -H 'Accept: application/json' http://localhost:3000/api/eval
```

รัน `npm run eval -- --demo` เพื่อสร้าง `data/cache/eval-report.json` ใหม่จาก [โจทย์และอันดับอ้างอิง](data/personas.csv) กับ [แคตตาล็อกชุดเดโม](data/README.md) คำสั่งใช้โหมดกฎ ไม่เรียก OpenAI และไม่ต้องมี Arena cache เดิม วิธีที่ไม่มีผลให้วัด เช่น baseline ที่ให้โมเดลเลือกโดยตรงในโหมดนี้ ไม่ได้คะแนนเป็นศูนย์ อัตราที่อันดับหนึ่งไม่ผ่านข้อจำเป็นนับเฉพาะโจทย์ที่มี `must_notes` ช่องว่างไม่ได้แปลว่าผ่าน ผลนี้ใช้เปรียบเทียบวิธีจัดอันดับบนชุดสังเคราะห์ ไม่ใช่ผลจากผู้ซื้อจริง

[ขั้นตอนซ้อมเดโม 6 นาที](docs/demo-rehearsal.md) ครอบคลุมโจทย์เครื่องปั่น วิธีเปิดรีวิวต้นทาง และวิธีลองค้นเว็บแยกจากชุดเดโม

## ลองค้นสินค้าจากเว็บ

ใส่ `OPENAI_API_KEY` และ `OPENAI_MODEL` ใน `.env.local` ตาม [ตัวอย่างการตั้งค่า](.env.example) แล้วเริ่ม `npm run dev` ใหม่โดยไม่ล้างสองค่านั้น หน้าแรกใช้ OpenAI Responses API ค้นจากเว็บผู้ผลิตและร้านค้าที่ระบบอนุญาต และแสดงไม่เกินสามรุ่นที่ยืนยันรุ่น ราคาไทย และแหล่งข้อกำหนดที่ต้องมีได้ ระบบไม่ดึงข้อมูลจาก Shopee ถ้าค้นเว็บไม่ได้ ให้แยกผลที่ติดป้าย **โหมดกฎ · ข้อมูลเดโม** ออกจากผลเว็บ ถ้าไม่พบรุ่นที่ยืนยันได้ ให้ลองค้นอีกครั้งโดยไม่อ้างว่ามีข้อเสนอจริง

## แนวทางที่สร้างและวิธีใช้ Codex

**AI-Native Products & Operations.** ตรงปกเปลี่ยนโจทย์ซื้อของให้เป็นข้อที่ตรวจทีละข้อได้ ใน Arena บทบาท Fit หาตัวที่เหมาะกับโจทย์ Value หาตัวที่คุ้ม และ Skeptic หารีวิวที่ค้าน ระบบตรวจว่าข้อความอ้างอิงอยู่ในรีวิวต้นทางจริง แล้วใช้โค้ด [คำนวณคะแนนและจัดอันดับ](docs/scoring.md) ไม่ให้โมเดลกำหนดคะแนน

- [PR #17](https://github.com/AYNO-I-KNOW/trongpok/pull/17) ใช้ Codex แก้การคัดผลค้นเว็บให้แสดงเฉพาะข้อเสนอไทยที่ตรวจได้ว่าตรงรุ่นและตรงเงื่อนไข
- [PR #20](https://github.com/AYNO-I-KNOW/trongpok/pull/20) ใช้ Codex ทำให้ผู้ซื้อเปิดข้อทักท้วงใน Arena และตรวจข้อความกับรีวิวต้นทางของรุ่นนั้นได้
- [ชุดโจทย์ Codex](docs/codex-prompts.md) บันทึกข้อกำหนดที่ใช้ทำงาน เช่น S04 ให้ปฏิเสธ quote ที่แต่งขึ้น และ S06 ให้วัดอันดับเทียบกับ baseline โดยแสดงค่าตามที่วัดได้แม้ baseline ชนะ

นี่คือ repo สาธารณะของตรงปก ไม่ใช่ fork ชุดสินค้าและรีวิวสังเคราะห์เป็นข้อมูลที่ทีมเตรียมไว้ก่อนตาม [บันทึกชุดข้อมูล](data/README.md) ส่วนเส้นทางค้นเว็บ การเปิดรีวิวจาก Arena และการสร้างรายงานซ้ำเป็นงานใน repo นี้
