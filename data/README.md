# ชุดข้อมูลเดโม

ทีมเตรียมเองทั้งหมด ห้ามคัดลอกชื่อสินค้า คำอธิบาย หรือรีวิวจาก Shopee (ToS ข้อ 3.1) และห้ามใช้ข้อมูลจาก `spike/` หรือ `price-spike/` ใช้ ChatGPT ร่างรีวิวจากสถานการณ์ที่ทีมกำหนดได้ แต่ต้องอ่านแก้ทุกอัน ช่วงเช้าวันงานให้แจ้งกรรมการว่าเป็นข้อมูลสังเคราะห์ที่เตรียมมาก่อน

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `categories/<id>.json` | คำถามแบบปุ่มของหมวดนั้น แต่ละตัวเลือกคือ requirement ที่ระบบตรวจ มี `blender` กับ `smartwatch` ให้แล้ว |
| `products/_example.json` | ตัวอย่างครบทุกฟิลด์ ระบบข้ามไฟล์ที่ขึ้นต้นด้วย `_` |
| `products/<id>.json` | สินค้า 1 ชิ้นต่อไฟล์ |
| `personas.csv` | โจทย์ผู้ใช้กับอันดับที่คนจัด ใช้วัดผลบนเวที |

## จำนวนขั้นต่ำคืนนี้

| หมวด | สินค้า | รีวิวต่อชิ้น | persona |
|---|---|---|---|
| blender | 8 | 15–25 | 4 |
| smartwatch | 8 | 15–25 | 4 |

สินค้าหมวดอื่นเพิ่มได้ตามสบาย ให้หน้าแรกดูมีของหลากหลาย แต่ไม่นับในการวัดผล หมวดใหม่ต้องมี `categories/<id>.json` ด้วย

## ออกแบบสินค้าให้ arena มีเรื่องเล่า

ในแต่ละหมวดต้องมีครบทุกแบบ:

- **ดาวสูงแต่ไม่เหมาะ**: 4.8★ ขายดี แต่ requirement สำคัญถูกรีวิวแย้ง เช่น สเปกบอกว่าปั่นน้ำแข็งได้ แต่รีวิวบอกว่ามอเตอร์ไหม้ (ดู `_example.json`)
- **แบรนด์ดังราคาแพง**: ผ่านทุกข้อ แต่ `features` ส่วนใหญ่ไม่ตรงกับคำถามใดเลย (ทำให้เห็นตัวเลขประหยัด)
- **ตัวคุ้ม**: ราคากลางหรือต่ำ ผ่าน must ทุกข้อ และมีรีวิวยืนยัน
- **ตัวที่หลักฐานบาง**: รีวิวที่พูดถึงเรื่องสำคัญน้อยกว่า 10 รีวิว ต้องขึ้นว่าข้อมูลไม่พอ
- **ตัวที่สเปกไม่ระบุ**: ไม่มี key ที่คำถามใช้ เพื่อให้ web search (S10) มีงานทำ หรือขึ้นว่า `unknown`

รีวิวในแต่ละชิ้นต้องมี: ดาวสูงแต่บ่น, บ่นขนส่ง, ประชดหรือแสลง ("ปกเทพ", "จกตา"), ชมลอยๆ และรีวิวสำเร็จรูป (`isTemplate: true`)

## ฟิลด์สินค้า

| ฟิลด์ | ความหมาย |
|---|---|
| `id` | ตัวพิมพ์เล็กคั่นด้วยขีดกลาง ตรงกับชื่อไฟล์ |
| `category` | ต้องตรงกับ `categories/<id>.json` |
| `specs` | key ต้องตรงกับ `spec.key` ในคำถามของหมวด |
| `features` | ฟีเจอร์ที่ขายอยู่ ใช้คำนวณ "ฟีเจอร์ที่จ่ายแต่ไม่ได้ใช้" |
| `shopeeUrl` | เว้นว่างได้ ถ้าว่าง ปุ่มเปิดใน Shopee จะไปหน้าค้นหาด้วยชื่อสินค้า |
| `stars`, `ratingCount` | ตัวเลขที่ Shopee โชว์ ใช้เป็น baseline |
| `claims[].checkable` | `false` เมื่อรีวิวพิสูจน์ไม่ได้ เช่น ของแท้ หรือทองแดงแท้ |
| `reviews[].isTemplate` | รีวิวสำเร็จรูป ระบบตัดทิ้ง |
| `reviews[].daysAgo` | อายุไม่เกิน 90 วันได้น้ำหนักเพิ่ม |

## persona (`personas.csv`)

| คอลัมน์ | ตัวอย่าง |
|---|---|
| `persona_id` | `b1` |
| `need_text` | `จะเปิดร้านกาแฟเล็กๆ ต้องปั่นน้ำแข็งวันละ 50 แก้ว` |
| `answers` | `use=ice;volume=cap-large;noise=;budget=3000` ใช้ id ของคำถามและ id ของ requirement |
| `labeler_a_top3`, `labeler_b_top3` | `blender-x|blender-y|blender-z` สองคนจัดแยกกัน ห้ามดูของอีกคน |
| `human_top3` | อันดับหลังคุยกันแล้ว |
| `must_notes` | สินค้าที่คนเห็นว่าไม่ผ่าน must พร้อมเหตุผลสั้นๆ |

จดอัตราที่ top-1 ของสองคนตรงกันไว้ ตัวเลขนี้คือเพดานที่ระบบทำได้
